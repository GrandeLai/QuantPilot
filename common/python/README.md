# quantpilot-common (Python)

Shared Python infrastructure for QuantPilot products. Imported by `apps/stock-assistant`.

## Modules

| Module | Purpose |
|---|---|
| `quantpilot_common.config` | Pydantic settings + env loading |
| `quantpilot_common.redis` | Redis client, pub/sub, order queue, price cache |
| `quantpilot_common.platform` | Shared platform contracts (DomainStatus, FactEnvelope, summary service) |
| `quantpilot_common.data` | Data fetchers (yfinance, akshare, on-chain), DuckDB storage, scheduler |
| `quantpilot_common.schemas` | Auto-generated types from `common/schemas/*.schema.json` (do not edit) |

## Constraints

- **Only depend on third-party libraries and stdlib**. No imports from `apps/*`.
- Schema-generated types (`schemas/`) are regenerated by `common/schemas/codegen.sh`; commit changes alongside source schemas.

## Local development

```bash
# From repo root
uv sync                            # syncs entire workspace including common/python
uv run --package quantpilot-common pytest common/python/tests/ -v
```
