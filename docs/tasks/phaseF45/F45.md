# Task F.45 — Commodity Channel Index (CCI) Panel

## Overview
CCI = (TP - SMA(TP, 20)) / (0.015 × MeanAbsDev(TP, 20))
Typical Price = (High + Low + Close) / 3
CCI > 100: overbought; CCI < -100: oversold.
Score = clip((CCI + 200) / 400 * 100, 0, 100).
