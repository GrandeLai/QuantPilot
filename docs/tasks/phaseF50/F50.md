# Task F.50 — Keltner Channel Panel

## Overview
Keltner Channel — EMA-centered volatility band using ATR width.

  Middle : EMA(close, 20)
  Upper  : EMA + 2 × ATR(10)   [ATR via Wilder EWM]
  Lower  : EMA − 2 × ATR(10)

Position within channel:
  position = (Close − Lower) / (Upper − Lower) × 100   clipped to [0, 100]
  (0 = at/below lower, 100 = at/above upper)

Score = percentile rank of position within last 252 bars × 100.

Secondary outputs:
- `above_upper`: Close > Upper band (potential trend breakout)
- `below_lower`: Close < Lower band (potential oversold)
- `channel_width_pct`: (Upper − Lower) / EMA × 100  (volatility proxy)
- `kc_position`: raw position value 0-100
