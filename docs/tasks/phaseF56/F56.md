# Task F.56 — DPO (Detrended Price Oscillator) Panel

## Overview
DPO removes the trend to highlight short-term cycles.

  DPO = Close − SMA(n, shifted back by n//2 + 1 bars)

Period n = 20. Offset = n//2 + 1 = 11.
Positive DPO → price above historical cycle average → bullish cycle.

Score = percentile rank of DPO in last 252 bars × 100.

Secondary outputs:
- `dpo_value`: float — latest DPO value
- `dpo_positive`: bool — DPO > 0
