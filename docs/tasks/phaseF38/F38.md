# Task F.38 — Bollinger Band Squeeze Panel

## Overview

squeeze detection (bandwidth at historical low), and composite score (0-100).

6. Score in [0, 100]; signal thresholds ≥80/≥60/≥40/≥20
7. `BollingerPanel` rendered in `RiskReviewCenter`
