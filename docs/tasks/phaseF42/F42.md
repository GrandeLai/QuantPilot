# Task F.42 — Money Flow Index (MFI) Panel

## Overview
MFI (Money Flow Index) — volume-weighted RSI oscillator using typical price × volume.
Typical Price = (H+L+C)/3; Raw Money Flow = TP × Volume; MFI = 100 - 100/(1+PMF/NMF)
over a 14-period window. Score mapping, signal thresholds, divergence detection.
