# Task F.47 — Rate of Change (ROC) Panel

## Overview
ROC = (Close - Close[n]) / Close[n] × 100  (default n=12).
Measures percentage price momentum over n periods.
Score = percentile rank of ROC within 1-year window × 100.
Secondary: ROC zero-line cross (bullish/bearish).
