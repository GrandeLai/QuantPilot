# Task F.61 — Chaikin Oscillator Panel

## Overview
Chaikin Oscillator — measures the momentum of the Accumulation/Distribution (AD) Line.

  Money Flow Multiplier (MFM) = ((Close - Low) - (High - Close)) / (High - Low)
  Money Flow Volume (MFV)     = MFM * Volume
  AD Line                     = cumulative sum of MFV
  Chaikin Osc                 = EMA(3, AD) - EMA(10, AD)

Score (0–100):
  - Percentile rank of Chaikin Osc in 252-bar rolling window × 100
  - Score ≥ 80 → strong_bull, ≥ 60 → bull, ≥ 40 → neutral, ≥ 20 → bear, else strong_bear
