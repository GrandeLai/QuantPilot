# Task F.44 — Williams %R Panel

## Overview
Williams %R = (Highest_High_14 - Close) / (Highest_High_14 - Lowest_Low_14) × -100
Ranges [-100, 0]. Score = (100 + %R) / 100 × 100 → [0, 100].
Overbought: %R > -20; Oversold: %R < -80.
