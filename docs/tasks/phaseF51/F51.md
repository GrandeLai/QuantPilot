# Task F.51 — Force Index Panel

## Overview
Elder's Force Index — combines price change and volume to measure the
"force" behind a price move.

  Raw FI(t) = (Close(t) − Close(t−1)) × Volume(t)
  Smoothed FI = EMA(Raw FI, 13)

Positive FI → bullish force; Negative FI → bearish force.

Score = percentile rank of smoothed FI within last 252 bars × 100.

Secondary outputs:
- `fi_positive`: bool — FI > 0
- `fi_direction`: "rising" | "falling" | "flat" (FI vs previous bar)
- `fi_normalized`: FI / (price × avg_volume) × 100  (scale-independent)
