# Task F.60 — Know Sure Thing (KST) Panel

## Overview
KST (Know Sure Thing) — composite momentum oscillator averaging ROC at four timeframes, weighted and smoothed.

  RCMA1 = SMA(10, ROC(10))
  RCMA2 = SMA(10, ROC(15))
  RCMA3 = SMA(10, ROC(20))
  RCMA4 = SMA(15, ROC(30))

  KST    = RCMA1×1 + RCMA2×2 + RCMA3×3 + RCMA4×4
  Signal = SMA(9, KST)

Score (0–100):
  - KST above/below zero: 40 pts
  - KST above/below signal line: 30 pts
  - Percentile rank of KST in 252-bar window × 30 pts
