# Task F.54 — Ultimate Oscillator Panel

## Overview
Ultimate Oscillator — combines three timeframes to reduce false signals.

  BP  = Close − Min(Low, PrevClose)          # Buying Pressure
  TR  = Max(High, PrevClose) − Min(Low, PrevClose)  # True Range
  Avg(n) = Sum(BP, n) / Sum(TR, n)
  UO  = 100 × (4×Avg(7) + 2×Avg(14) + Avg(28)) / (4+2+1)

UO ranges 0–100. Classic levels: >70 overbought, <30 oversold.

Score = percentile rank of UO in last 252 bars × 100.

Secondary outputs:
- `uo_value`: float — latest UO (0–100)
- `uo_overbought`: bool — UO > 70
- `uo_oversold`: bool — UO < 30
