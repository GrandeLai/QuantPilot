# Task F.62 — Elder Ray Index Panel

## Overview
Elder Ray Index — measures buying and selling pressure relative to an EMA.

  EMA(13, Close) = base trend line
  Bull Power     = High - EMA(13)   [positive when bulls push price above EMA]
  Bear Power     = Low  - EMA(13)   [negative when bears push price below EMA]

Score (0–100):
  40 pts  Bull Power > 0 (bullish) else 0
  30 pts  Bear Power rising (current > previous, less negative = bears weakening) else 0
  30 pts  percentile rank of (Bull Power - Bear Power) in 252-bar window
