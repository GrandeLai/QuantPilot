# Task F.67 — Mass Index Panel

## Overview
Mass Index — a volatility indicator that uses the high-low range to identify
trend reversals via a "reversal bulge" pattern.

  EMA1(n)       = EMA(9, High − Low)
  EMA2(n)       = EMA(9, EMA1)
  Mass Index(m) = Σ(EMA1 / EMA2)  over m=25 bars

Reversal bulge: Mass Index crosses above 27 then drops below 26.5
  → typical interpretation: trend reversal imminent.

Score (0–100):
  40 pts  Mass Index < 26.5 (not in elevated-volatility zone)
  30 pts  Mass Index trending downward (5-bar change < 0)
  30 pts  inverse percentile rank in 252-bar window × 30
          (lower MI relative to history → higher score, calmer market)
