# Task F.57 — TSI (True Strength Index) Panel

## Overview
TSI — double-smoothed price momentum oscillator.

  PC       = Close − Close[−1]   (price change)
  TSI      = 100 × EMA(EMA(PC, 25), 13) / EMA(EMA(|PC|, 25), 13)
  Signal   = EMA(TSI, 7)

Range: −100 to +100. Typical overbought > +25; oversold < −25.

Score = percentile rank of TSI in last 252 bars × 100.

Secondary outputs:
- `tsi_value`: float — latest TSI (−100 to +100)
- `signal_line`: float — 7-period EMA of TSI
- `tsi_positive`: bool — TSI > 0
- `tsi_above_signal`: bool — TSI > signal line
