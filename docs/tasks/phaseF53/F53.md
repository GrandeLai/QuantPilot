# Task F.53 — Aroon Indicator Panel

## Overview
Aroon — measures how many periods have passed since the n-period high/low.

  Aroon Up   = ((n - periods since n-period high) / n) × 100
  Aroon Down = ((n - periods since n-period low)  / n) × 100
  Aroon Oscillator = Aroon Up − Aroon Down

Period n = 25 (standard).

Score = percentile rank of Aroon Oscillator within last 252 bars × 100.
  Oscillator > 0 (Up > Down) → bullish; < 0 → bearish.

Secondary outputs:
- `aroon_up`: float — Aroon Up (0-100)
- `aroon_down`: float — Aroon Down (0-100)
- `aroon_oscillator`: float — Up - Down (-100 to +100)
- `aroon_bullish`: bool — oscillator > 0
