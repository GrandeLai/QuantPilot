# Task F.58 — Donchian Channels Panel

## Overview
Donchian Channels — rolling high/low price envelope, classic breakout indicator.

  Upper   = max(High, n periods)
  Lower   = min(Low,  n periods)
  Middle  = (Upper + Lower) / 2
  Position = (Close − Lower) / (Upper − Lower) × 100   [0–100]

Period n = 20. Position 100 = at upper band (breakout up), 0 = at lower band.

Score = percentile rank of Position in last 252 bars × 100.

Secondary outputs:
- `upper`: float — upper channel price
- `lower`: float — lower channel price
- `middle`: float — midpoint
- `position`: float — 0–100 where Close sits in the channel
- `channel_width_pct`: float — (Upper−Lower)/Middle × 100 (volatility proxy)
