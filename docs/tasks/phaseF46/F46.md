# Task F.46 — Average True Range (ATR) Panel

## Overview
ATR = Wilder EWM(alpha=1/14) of True Range (max of H-L, |H-prevC|, |L-prevC|).
ATR% = ATR/Close×100 (normalized volatility).
ATR% percentile over 1-year window classifies volatility regime.
Score combines trend (price vs SMA20/SMA50) with ATR confirmation:
  raw ∈ [-4.5, 4.5] → (raw+4.5)/9×100 → [0,100].
