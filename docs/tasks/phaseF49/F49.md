# Task F.49 — VWAP Panel

## Overview
Volume Weighted Average Price (VWAP) — institutional reference price.

Rolling 20-day VWAP (daily bars):
  TP  = (High + Low + Close) / 3
  VWAP = Σ(TP × Volume) / Σ(Volume)  over rolling 20-day window

Score = percentile rank of (Close / VWAP − 1) × 100  within last 252 bars.
  Above VWAP → positive deviation → higher percentile rank.

Secondary outputs:
- `vwap_deviation_pct`: (Close − VWAP) / VWAP × 100
- `above_vwap`: bool
- `vwap_slope`: "rising" | "falling" | "flat" (compare today vs 5 bars ago)
