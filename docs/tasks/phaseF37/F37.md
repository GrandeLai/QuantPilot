# Task F.37 — MACD Signal Panel

## Overview
Implement MACD (Moving Average Convergence Divergence) indicator: EMA12, EMA26, Signal9,
Histogram, score (0-100), signal classification, recent crossover detection.

## Acceptance Criteria
1. All tests pass (`pytest tests/test_macd.py`), ≥ 16 tests
2. Ruff and Mypy clean
3. Vite build passes
4. `compute_macd` never raises; returns `data_available=False` on yfinance error
5. `GET /api/macd?ticker=` returns 200; without ticker returns 422
6. Score in [0, 100]; signal thresholds ≥80/≥60/≥40/≥20
7. `MACDPanel` rendered in `RiskReviewCenter`
