# Task F.48 — Parabolic SAR Panel

## Overview
Parabolic SAR (Stop and Reverse) — a trend-following indicator that places dots
above or below price to indicate trend direction and adaptive stop levels.

Algorithm (Wilder):
- AF starts at 0.02, increments by 0.02 each time EP is updated, capped at 0.20
- Uptrend:  SAR(t) = SAR(t−1) + AF × (EP − SAR(t−1))  where EP = highest Close since trend start
- Downtrend: SAR(t) = SAR(t−1) + AF × (EP − SAR(t−1))  where EP = lowest Close since trend start
- Flip: when Close crosses SAR, reverse trend; reset AF = 0.02, EP = first bar's extreme

Score = percentile rank of (Close / SAR − 1) within a 252-bar rolling window × 100.
  Positive (price > SAR) values rank high; negative rank low.

Secondary outputs:
- `sar_bullish`: bool — Close > SAR
- `sar_distance_pct`: (Close − SAR) / Close × 100 (negative in downtrend)
- `trend_bars`: consecutive bars in current trend (uptrend positive, downtrend negative)
- `sar_direction`: "up" | "down"
