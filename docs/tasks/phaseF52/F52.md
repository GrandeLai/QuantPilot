# Task F.52 — TRIX Panel

## Overview
TRIX — 1-period percentage rate of change of a triple-smoothed EMA.
Filters out noise through triple smoothing; zero-line crossovers are high-quality signals.

  EMA1 = EMA(Close, 15)
  EMA2 = EMA(EMA1, 15)
  EMA3 = EMA(EMA2, 15)
  TRIX = (EMA3 − EMA3[−1]) / EMA3[−1] × 100
  Signal = EMA(TRIX, 9)

Score = percentile rank of TRIX within last 252 bars × 100.
  Positive TRIX (above zero) → bullish; negative → bearish.

Secondary outputs:
- `trix_positive`: bool — TRIX > 0
- `trix_above_signal`: bool — TRIX > Signal line (bullish crossover)
- `signal_line`: 9-period EMA of TRIX
