# Task F.55 — Supertrend Panel

## Overview
Supertrend — ATR-based adaptive trend-following indicator.

  ATR(n)      = Wilder EMA of True Range (n=10)
  UpperBand   = (High+Low)/2 + Factor × ATR   (Factor=3.0)
  LowerBand   = (High+Low)/2 − Factor × ATR
  Supertrend  = LowerBand when trend is UP; UpperBand when trend is DOWN
  Trend flips UP   when Close > previous UpperBand
  Trend flips DOWN when Close < previous LowerBand

Score = percentile rank of (Close − Supertrend) / Close × 100 in last 252 bars × 100.
  Positive (above Supertrend) → bullish; negative → bearish.

Secondary outputs:
- `supertrend_value`: float — current Supertrend line price
- `supertrend_bullish`: bool — close > Supertrend (uptrend)
- `distance_pct`: float — (Close − Supertrend) / Close × 100
