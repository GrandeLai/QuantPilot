# Task F.85 — Pivot Points Panel

## Overview

Classic Pivot Points use the previous session's high, low, and close to derive
intraday and swing support/resistance levels:

`PP = (High + Low + Close) / 3`

The panel exposes PP, R1/R2/R3, S1/S2/S3, a 0-100 directional score, and a
signal badge for quick technical review.
