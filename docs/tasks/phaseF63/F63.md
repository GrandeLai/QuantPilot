# Task F.63 — Vortex Indicator Panel

## Overview
Vortex Indicator — directional trend strength using true-range-based price movement.

  TR      = max(High-Low, |High-PrevClose|, |Low-PrevClose|)
  VM+     = |High[i] - Low[i-1]|   (upward movement)
  VM-     = |Low[i]  - High[i-1]|  (downward movement)
  +VI(14) = sum(VM+, 14) / sum(TR, 14)
  -VI(14) = sum(VM-, 14) / sum(TR, 14)

  Signal: +VI > -VI → bullish; -VI > +VI → bearish
  Spread = +VI − -VI

Score (0–100) = percentile rank of Spread in 252-bar window × 100.
